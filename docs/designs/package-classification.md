# 包分类与发布协议 (Package Classification)

> 文档类型: 仓库级设计
> 适用对象: 本仓维护者与 AI Agent
> 前置: [集合仓定位](collection-positioning.md)

## 三类包

集合内每个包恰属以下三类之一:

| 类属           | 判据 (确定性字段)                                                   | 发布     | 例                               |
| -------------- | ------------------------------------------------------------------- | -------- | -------------------------------- |
| **CLI 工具**   | `package.json` 有 `bin` 字段                                        | 发 npm   | `@iyowei/sweep-node-modules-cli` |
| **公开库**     | 无 `bin`, 且不在私有登记册                                          | 发 npm   | `@iyowei/sweep-node-modules`     |
| **仓内私有库** | 无 `bin`, 登记于根 `package.json` 的 `multi-release.ignorePackages` | 不发 npm | (待首个私有库出现时登记)         |

判据全部来自确定性字段, 不设人工分类清单: 类属由 `bin` 字段与 `ignorePackages` 登记**派生**, 无需在别处复述。

## 各类的工程要求

| 要求                            | CLI 工具                     | 公开库   | 仓内私有库 |
| ------------------------------- | ---------------------------- | -------- | ---------- |
| 双语文 README (英文主)          | 必须                         | 必须     | 不需要     |
| 发布自证闸门 (`verify:release`) | 必须                         | 必须     | 不需要     |
| 金样本语料 (conformance 档)     | 视工具                       | 视对外面 | 不需要     |
| 契约测试 + 双载体测试           | 必须                         | 必须     | 必须       |
| 通用闸门 (引用 / 示例 / 散落)   | 仓库级自动覆盖, 无需按包配置 |          |            |

「视工具 / 视对外面」的档位判定与豁免登记沿用转写契约套件的覆盖表纪律 (见 `../protocol/README.md`)。

## 新增成员的最低门槛

1. 包落入 `packages/` 且命名 `@iyowei/<name>` (工具配套可 `<name>-cli`);
2. 按上表补齐其类属要求的工程件;
3. 依赖方向符合[依赖方向纪律](dependency-direction.md);
4. 私有库须同时登记 `ignorePackages` (判据与机制同表);
5. 根 README 的成员清单加一行。

## 与发布链的边界

版本判定、发布通道与自证机制属既有发布链设计 (`../development.md` 与 ADR 0009 / 0010), 本协议只规定「谁发布、按什么类属要求」, 不改发布链行为。
