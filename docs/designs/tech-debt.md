# 技术债登记 (Tech Debt Registry)

> 文档类型: 仓库级设计 (登记册)
> 适用对象: 本仓维护者与 AI Agent

## 纪律

- 每笔债必须有**可判定的解除条件**: 写不出「何时可清除」的条目不是债, 是伪装成债的永久妥协, 应改记为[明说边界](collection-positioning.md)或直接删除;
- 破例 (如依赖方向例外) 必须先在此登记再落地, 见[依赖方向纪律](dependency-direction.md);
- 解除后移入「已偿付」区, 保留原条目一行 (含解除日期与处置), 兑付历史不删除。
