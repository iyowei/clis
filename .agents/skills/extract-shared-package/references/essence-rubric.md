# 本质行为抽象与 Rust 边界设计准则

本手册聚焦 AI 负责的 **C 类语义裁决**; 数值门槛、驼峰防泄漏、垃圾桶词禁令、冷却天数计时与文件体检均由脚本强制执行并直接吐出清晰报错, 本文件不复述脚本规则细节。

## 一、本质剥离三问 (拒斥具象与垃圾桶包)

实读候选克隆源码后, 按以下三步将代码从原产品语境中彻底抽干:

1. **它剥去业务名词后在解决什么单一问题?** 用「一个动作 + 一个通用对象」概括。凡是无法一句话讲清单一职责、需要用 `utils`/`helpers`/`common` 兜底的集合, 禁止抽包, 直接 `reject`。
2. **外部完全陌生的开发者能直接安装看懂吗?** 接口名、参数字段、类型与错误码必须彻底中性化 (例如 `sweepTarget` → `targetPath`, `coddPreset` → `presetSpec`)。
3. **剥离外层业务胶水后的净复用价值是否大于建包税?** `cutCost` (内部相对依赖闭合数) 过高或逻辑不足 15 行且无独立契约的琐碎片段, 应直接否决或仅保留局部抽象, 拒绝纳米包。

### 具象逐物 vs 行为本质对照

| 领域问题     | 具象逐物反模式 (禁止)                          | 行为本质正模式 (采纳)                                                           |
| :----------- | :--------------------------------------------- | :------------------------------------------------------------------------------ |
| **终端列宽** | `sweep-render-utils` (导出 `clipLineForSweep`) | `@iyowei/tty-width` ("终端可见列宽计算、ANSI 剥离与定宽安全裁剪原语")           |
| **颜色降级** | `codd-cli-colors` (耦合特定产品深浅主题结构体) | `@iyowei/tty-color` ("遵循 TTY / NO_COLOR / CI 约束的轻量 ANSI SGR 样式适配器") |
| **参数解析** | `cli-shared-args` ("解析自更新和预设参数")     | `@iyowei/argv-flags` ("零依赖的确定性短长旗标与位置参数解析器")                 |

## 二、退化私库的冷静期与裁决原则 (防震荡与保边界)

脚本自动按传递可达业务产品域 (`cli` / `api`) 统计每个 `shared-lib` 的真实支撑度 (A/C/D 通过中间库间接依赖仍算有效支撑), 仅保留提示给你决策的边界法则:

- **冷却期 (`cooling-down`) 不动作**: 单域私库默认观察 14 天、零消费私库默认观察 7 天 (命令行 `--cooldown-days` / `--dead-cooldown-days` 可覆写); 期间任意时刻新接入使域数 `>= 2`, 计时与暂缓记录自动清零。
- **公开孤立库 (`orphaned-public-lib`) 禁自动删除**: 对外非 `private` 包已承载社区契约, 脚本仅报警交由人工决定独立演进或 npm deprecate。
- **期满回收必须留存独立边界**: 哪怕退化回唯一消费方 A, 也**绝不能拆散揉进 A 原有的业务逻辑文件**, 必须以独立子目录 (`src/<mod>/index.ts` + 单测) 或自包含单文件方式寄生在 A 内, 维持零反向依赖 (`cutCost = 0`), 确保将来若有新产品需求时随时可无痛再次抽出。

## 三、TS → Rust 转写友好设计原则

编写或重构共享模块时, 参考扫描报告给出的 `rustReadiness` 得分与 `hazards`:

1. **强边界拆分**: 将纯数据计算内核与宿主副作用 (`fs`、`child_process`、`tty`、`env`、`http`) 通过依赖注入接口参数彻底分离 (`ioBoundaryMixed === false`)。
2. **明确静态类型代数结构**: 禁 `any`、禁用 `Record<string, unknown>` 动态字典与开放索引, 改用判别联合 (`enum`) 或确定字段接口 (`struct`), 所有导出函数带显式参数与返回类型。
3. **显式控制流与状态**: 避免无类型自由 `throw` (改 `Result` 返回联合) 与多层嵌套闭包原地改写外层 `let` 状态 (改状态对象方法或纯数据转换); 若为树/图递归结构, 显式注明索引池或 `Box` 边界。
4. **保持独立闭环可验收**: 便于未来用 TS 或 Rust 实现后直接接入 [scripts/transcription/](../../../../scripts/transcription/) 做等价行为契约验证。
