> 判据 (见 [套件门面](../README.md)「维护规则」): 每条语料 `specRefs` 非空且指向真实条款; 产出「契约条款 × 语料」覆盖表, 未被覆盖的条款要么补语料, 要么在第二节显式登记豁免与替代护栏。
