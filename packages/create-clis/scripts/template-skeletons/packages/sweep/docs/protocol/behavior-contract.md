# 行为契约 (behavior contract · 示例骨架)

> 用途: 增强档 (`--tier full`) 预置的最小可运行行为契约骨架 (覆盖矩阵与变异自证登记见 [coverage.md](conformance/coverage.md))。落地真实业务时替换为自己的条款与金样本语料。

## BC · 核心行为

| 编号  | 条款                                                           | 权威出处                     | 可验收              |
| ----- | -------------------------------------------------------------- | ---------------------------- | ------------------- |
| BC-01 | 传入目标名称时输出规范问候语 `Hello, <name>!`, 净化控制字符    | `packages/{{NAME}}/src/index.ts` | CLI 黑盒 + API 黑盒 |

## OF · 输出规格

| 编号  | 条款                                                | 权威出处                             | 可验收   |
| ----- | --------------------------------------------------- | ------------------------------------ | -------- |
| OF-01 | `--version` / `-V` 打印当前包版本号并退 0, stderr 空 | `packages/{{NAME}}-cli/src/cli.ts` | CLI 黑盒 |
