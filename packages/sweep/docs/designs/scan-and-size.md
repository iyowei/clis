## 扫描算法 (多预设锚定与自定义规则引擎)

生产扫描器 (`packages/sweep/src/scan-parallel.ts` + `scan-match.ts` + `scan-roots.ts`) 在完整保留 7 轮性能优化成果的基础上, 泛化为面向多技术栈预设与自定义规则的统一遍历引擎:

1. **根预检与独立多根并发**: 并发校验每个输入根的可访问性与目录类型, 按错误码区分原因 (`SCAN_ROOT_MISSING` / `SCAN_ROOT_UNREADABLE` / `SCAN_ROOT_NOT_DIR` / `SCAN_ROOT_UNAVAILABLE`), 按平台归一化 realpath 去重 (win32 大小写折叠); 互不包含的独立根共享 32 路回调并发池, 存在嵌套包含关系的根自动回落串行以严守先到先得的 `ScanHit.root` 归属顺序。
2. **单次 `readdir` 构造同级文件表 (零多余磁盘 IO 锚定)**: 每进入一个目录调用一次原生回调 `readdir(dir, { withFileTypes: true })`, 先线性提取该目录内所有普通文件名到 `siblingFiles: ReadonlySet<string>`。对绝大多数预设 (`node` 查 `package.json`、`rust` 查 `Cargo.toml`、`java` 查 `pom.xml`/`build.gradle*`/`settings.gradle*`、`python` 查 `pyproject.toml`/`requirements.txt`、`cpp` 查 `CMakeLists.txt`), 同级锚定校验为内存 `O(1)` 查询, 零额外 syscall; 仅内嵌指纹 (`pyvenv.cfg`、`CMakeCache.txt`) 与自定义规则 `olderThanDays` 执行一次轻量 `lstat`。
3. **符号链接与 `.git` 硬跳过**: 任何 `entry.isSymbolicLink()` (无论指向文件还是目录) 既不跟进也不纳入目标命中; 目录名 `.git` 恒定剪枝跳过。
4. **全局排除与 `.gradle` 双重角色裁决**: 进入目录时若命中 `exclude` 即整棵子树跳过; 唯一受控例外是 [ADR 0022](../adrs/0022-config-v2-presets-and-rules.md) 裁定的项目级 `.gradle`: 当 `java` 预设激活、用户未显式指定 `exclude` (或未在显式 `exclude` 与 `presets.java.exclude` 中排除 `.gradle`)、目录不位于家目录本体 (`~/.gradle` 仍严格保护) 且同级存在 Gradle 锚点时, 放行该项目级 `.gradle` 进入预设判定并剪枝; 其余任何 `.gradle` (含 `~/.gradle` 及无 Gradle 锚点的目录) 严格剪枝跳过, 严禁回压栈下钻其内部子树。
5. **目录命中剪枝 vs 未锚定回压下钻**:
   - 候选目录通过预设锚定或自定义规则 (`kind: "dir" | "any"`) 命中时, 记录为目标并**立即剪枝停止下钻** (防止嵌套目录与子产物重复命中);
   - 候选目录名撞上预设通用名 (如普通业务文件夹名为 `target`、`build`、`venv` 或无 `package.json` 的 `node_modules`, 不含恒定剪枝的 `.gradle`) 但未通过锚定校验时, **不记入命中并将其回压遍历栈继续下钻**, 确保内部真实子项目不被漏扫;
   - 普通文件命中 (`os-junk` 预设或 `kind: "file" | "any"` 规则) 记录后继续扫描同目录其余项。
6. **白名单与局部名单语义**: 全局 `include` 与预设/规则级局部 `exclude` / `include` 均按自根下级起的祖先目录名链判定; 全局 `exclude` 恒优先于 `include`, 局部名单仅进一步收紧范围; `excludeMatches` / `includeMatches` 持续统计并暴露未命中拼写 (默认护栏项零命中不告警, 且白名单命中计数独立于排除优先)。
7. **多源去重与动作保守合并**: 跨预设、跨规则或跨多根命中同一真实路径 (`dedupeKey(realPath)`) 时只保留一条 `ScanHit` (按 `target` 码点升序输出), 携带 `entryKind` (`'dir' | 'file'`)、`source` (`{ kind: 'preset', name }` 或 `{ kind: 'rule', name }`) 与 `action` (`'delete' | 'trash'`); 若多个命中的动作冲突, **`'trash'` 永远覆盖 `'delete'`**。
8. **根自身仅作容器**: 根路径自身不作为被清理目标记录。根本身是符号链接时只读扫描仍照常跟进 (删除侧则由安全闸第五不变量拒绝, 见 [删除安全闸](deletion-guard.md))。

**实现裁定 (基准 r1-r4 与 7 轮收敛)**: 扫描采用**原生回调有界并发池 (`CONCURRENCY = 32`) + 显式 LIFO 栈** (零深递归栈溢出风险, 真实工作区 4.8× 提速); 入口根仅调用一次 `path.join` 规范前缀, 深层派生目录直接字符串拼接零 `path.join` 开销; 候选参照实现 (`scan-prune` / `scan-native`) 保留供基准对比与一致性对撞回归。

## 体积统计 (已裁定: 策略 A 双轨)

同时支持目录目标与普通文件目标 (`entryKind: 'dir' | 'file'`) 的体积核算:

- **统计口径**: `du` 快路径 = 磁盘占用 (`'disk-usage'`, macOS / Linux, 与 Finder 一致); 纯 JS 实现基线 = 逻辑字节 (`'logical-bytes'`, 无 `du` 平台及全部 Windows, 与 Explorer「大小」列一致); 同一 `measure()` 调用内口径恒一。
- **快路径 (`size-du.ts`)**: POSIX 上有 `du` 时, `≤ 4` 目标单进程直跑 (`du -sk -- <paths...>`, `--` 防止 `-` 开头路径被误作选项); `≥ 5` 目标按轮询交错切分为 2~6 批 (自适应 CPU 核心数, 单批受 128 KiB `ARG_MAX` 安全上限保护) 有界并发执行并流式上报进度, 每批独立做集合一致性 fail-safe 校验。
- **纯 JS 基线 (`size-js.ts`)**: 无 `du` 平台 (含全部 win32, 见行为契约 EC-03) 走跨目标共享有界原生回调 I/O 池 (`IO_CONCURRENCY = 48`, 最多 6 个目标重叠在途, 零每文件 Promise 分配, 进度按 `target` 升序滑动发射); 普通文件直接以 `lstat.size` 计入, 目录递归累加不跟随符号链接。
- **三桶完备划分**: 返回 `entries` (测得字节) / `unmeasured` (存在但测不到, 不得静默移出清单, 下游占位展示且不进清理批) / `gone` (扫描命中、测量时已消失, BC-13) 及 `warnings` (非致命告警); `entries ∪ unmeasured ∪ gone` 恰好构成全部输入路径的互不相交划分, 三桶均按 `target` 升序。
- **解析防御与非 TTY `du` 输出形态**: `du` 通过管道捕获 stdout (非终端, 文件名按输入原样成行, 实测覆盖 GNU du 9.12 与 BSD du); 解析后做多重集一致性校验, 不一致则整批降级为 `unmeasured` 并附告警; 含 `\n` / `\r` 的路径在构造命令前即拒收防拆行注入。
- **设备边界口径差异 (登记)**: 体积计算回答「占多大」, 按目标整体占用统计 (未启用 `du -x`); 删除面回答「能不能删」, 对跨设备目标默认跳过 (见 [删除安全闸](deletion-guard.md)「设备边界」)。

## 性能要点

- 每次 `readdir(..., { withFileTypes: true })` 同时拿到条目类型与内存同级文件集合, 绝大多数预设锚定校验零额外磁盘 IO;
- 目录命中即剪枝, 跳过 `.git` 与全部符号链接, 避免钻入巨型依赖树内部;
- 显式 LIFO 栈 + 32 路回调并发池填满内核 I/O 队列而非堆深递归;
- 体积统计批量并发或跨目标共享回调池完成, 杜绝逐目标独立 fork。

## 错误与边界

| 场景                                 | 处置                                                                         |
| ------------------------------------ | ---------------------------------------------------------------------------- |
| 目录不可读                           | 记 `SCAN_DIR_UNREADABLE` 告警并跳过, 不中断扫描                              |
| 某根不存在 / 不可读 / 不是目录       | 按 errno 分类记 `SCAN_ROOT_*` 告警并跳过该根, 不影响其余根                   |
| 存在但测不到体积                     | 归 `unmeasured` (`SIZE_UNMEASURED_*`), 下游占位展示且拒进清理批 (退出码 `1`) |
| `du` 输出集合不符 / 路径含换行控制符 | 整体或单条安全降级为 `unmeasured` 并附结构化告警, 严禁凭猜测字节放行清理     |
| 路径过深超出 `PATH_MAX`              | `realpath` 失败时退化为按字面路径去重 (已知平台边界)                         |
