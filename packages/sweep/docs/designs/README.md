# sweep 产品设计索引 (按推荐阅读顺序)

> 文档类型: 包级产品设计索引 (两级分层规则见[文档分层协议](../../../../docs/designs/docs-layering.md); 包文档入口见[上级](../README.md))
>
> 阅读顺序: 先总后分; 分册按数据流从外到内: 对外契约 ([可编程 API 面](api-surface.md) / [CLI 命令面与输出](../../../sweep-cli/docs/designs/cli-surface.md)) → 配置 (扫描与规则的判定依据) → 扫描与体积 (多预设锚定遍历与双轨测体积) → 删除安全闸 (泛化不变量、三端回收站与执行语义); 接下来是转写双面覆盖 (验收体系); 安全总账与架构总览收尾 (后者最好在翻过两包源码 `packages/sweep*/src` 之后再读)。

| 2    | [可编程 API 面](api-surface.md)                                | API 包对外契约: 两级导出面、预设/规则/回收站/迁移原语、错误码体系、进度与取消模型              |

| 10   | [转写双面覆盖](transcription-dual-surface.md)                  | 怎么验收: 转写套件与 CLI / API 双面黑盒验收机制、契约三档口径 (先读可编程 API 面)              |
