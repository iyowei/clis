# 行为契约 (behavior contract)

> 用途: 语料 `specRefs` 指向的就是这里; 每条语料的期望都必须能从这里的条款原文推导出来 (**严禁「跑一遍记下来」式捕获**)。
> 条款的权威出处以包级设计文档 (`packages/sweep/docs/designs/` 与 `packages/sweep-cli/docs/designs/`) 及产品级 ADR (`packages/sweep/docs/adrs/0021..0024`) 为主, 实现级细节以各条标注的代码载体为准; 本文件把相关内容按条款编号重新组织, 面向「转写与验收」。
>
> 可验收列 (三档, 可并列): `CLI 黑盒` = 可以跑 CLI 命令 (`sweep`) 来验收; `API 黑盒` = 该条款有经 harness 协议做 API 面验收的通道 (机制与语料见 `packages/sweep/docs/designs/transcription-dual-surface.md`, 每条的落地状态与豁免见 `conformance/coverage.md`); `模块级` = 黑盒覆盖不到的, 由对应的模块级测试钉死并注明理由。两档并列就是双面覆盖。
